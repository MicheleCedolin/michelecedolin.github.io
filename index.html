Front page

Hard optimization problems, made usable by anyone

Michele Cedolin is building browser-based solvers for vehicle routing and location-routing problems, and studies forecasting, supply chains and multi-criteria decision-making.

By Michele Cedolin

Industrial engineering is full of problems that are easy to state and hard to solve: where to open depots, which vehicle serves which customer, and in what order. The solvers presented here turn heuristics from the research literature into interactive tools for the browser.

Each solver is designed to run in an ordinary web page: load an instance, run an algorithm and inspect the routes it builds, with nothing to install and no account to create. The tools are being finalised and will be released one at a time.

The same mindset runs through the rest of the work, from forecasting and the bullwhip effect to facility location and data envelopment analysis: make the method clear enough that others can use it, check it and build on it.
